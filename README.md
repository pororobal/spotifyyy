# SpotiLyric

Spotify의 활성 미디어 세션에서 현재 곡과 재생 위치를 읽고, LRCLIB의 동기화 가사를 유체형 배경 위에 표시하는 Android 앱입니다.

## 초안 피드백과 반영 내용

첨부된 초안의 제품 방향은 명확하고, `NotificationListenerService → MediaSessionManager → LRCLIB → Compose UI` 흐름도 적절합니다. 다만 그대로 붙여 넣으면 설명과 실제 동작이 어긋나거나 경계 조건에서 문제가 생기는 부분이 있어 다음처럼 수정했습니다.

- 원본의 “단어 단위 하이라이트”는 실제로 단어 타임스탬프가 아니라 한 줄의 시작·종료 시간에 따른 가로 스윕이었습니다. 이 버전은 정확히 **줄 단위 진행 효과**로 정리했습니다. 진짜 단어 단위 효과는 LRCLIB의 `lyricsfile` 내 word timing을 별도로 파싱해야 합니다.
- 마지막 가사 줄의 종료 시간을 `maxOf(start + 4초, 전체 길이)`로 잡던 로직은 곡 길이를 넘어갈 수 있어, 전체 길이가 유효하면 그 시점에서 끝나도록 수정했습니다.
- 재생 위치 보간의 상한이 사실상 무제한이던 부분을 곡 길이로 제한했습니다.
- `/api/get`에 곡명·아티스트·앨범·길이를 먼저 보내 정확 매칭하고, 실패할 때만 `/api/search` 결과를 점수화하는 방식으로 바꿨습니다.
- 네트워크 오류, 연주곡, 미등록 가사, 권한 미허용 상태를 각각 구분해 안내합니다.
- 설정 화면에서 돌아올 때 수명주기 이벤트로 권한을 재확인하고 미디어 리스너를 재연결합니다.
- 서비스 연결 해제, 세션 종료, 곡 전환 때 컨트롤러를 안전하게 다시 선택합니다.
- LRC의 1~3자리 분수 초와 한 줄의 복수 타임스탬프를 지원하며 파서 테스트를 추가했습니다.
- Android 13 이상에서 사이드로드 앱의 알림 접근 스위치가 막힐 때 필요한 ‘제한된 설정 허용’ 안내를 추가했습니다.

## 요구 사항

- Android 12(API 31) 이상
- Spotify Android 앱
- 인터넷 연결(LRCLIB 가사 조회)
- 알림 접근 권한

## Android Studio에서 빌드

1. Android Studio에서 이 폴더를 엽니다.
2. 프로젝트가 요청하면 Android SDK Platform 35와 Build Tools를 설치합니다.
3. Gradle 동기화가 끝나면 `Build > Build Bundle(s) / APK(s) > Build APK(s)`를 선택합니다.
4. 생성 파일은 `app/build/outputs/apk/debug/app-debug.apk`입니다.

명령줄에서는 Android SDK 경로가 설정된 상태에서 다음을 실행합니다.

```bash
gradle assembleDebug
```

USB 디버깅이 켜진 기기에 설치하려면:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 처음 실행

1. 앱의 **알림 접근 허용하기** 버튼을 누릅니다.
2. 목록에서 **SpotiLyric 미디어 연동**을 켭니다.
3. 스위치가 비활성화되어 있으면 시스템의 SpotiLyric 앱 정보 화면에서 우측 상단 메뉴를 열고 **제한된 설정 허용**을 먼저 선택합니다.
4. Spotify에서 곡을 재생하고 SpotiLyric으로 돌아옵니다.

## 알려진 한계

- Spotify가 제공하는 미디어 메타데이터와 컨트롤 기능에 의존하므로 일부 기기·곡·Spotify 버전에서는 앨범 아트 또는 탐색 기능이 제한될 수 있습니다.
- LRCLIB에 해당 버전의 동기화 가사가 없으면 가사를 표시할 수 없습니다.
- 현재 하이라이트는 LRC 줄 구간 안에서의 시각적 진행률입니다. 개별 단어 발음 시각과 일치하는 word sync는 다음 단계 기능입니다.
- 앱은 현재 곡 메타데이터를 로컬 메모리에서만 사용합니다. 가사 검색을 위해 곡명·아티스트·앨범·길이를 LRCLIB에 전송합니다.
